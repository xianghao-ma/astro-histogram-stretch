# 彩色图的线性背景中性化与配色

## 顺序与边界

默认顺序：确认线性 RGB → 选择并检查背景区 → 背景中性化 → 保持背景中性的线性配色 → 共享 MTF 拉伸 → 检查颜色和背景。

只在原始或已配准合成的线性 RGB 浮点文件上修改颜色。允许的颜色变换仅为每通道乘一个正的有限常数及加减一个有限常数；系数在整幅图上固定。不得使用 gamma、曲线、饱和度、HSV/Lab、局部增益、颜色替换或对已拉伸 PNG 调色。不得以新增平滑或局部背景减除代替颜色调整。已有输入的配准、平滑和线性增益需记录，不反复施加。找不到线性输入时先取得线性数据，不从显示图猜测反演。

保留源文件和负值，保存新的浮点线性结果；配色阶段不截断到 [0,1]。之后的共享 MTF 是显示拉伸步骤，与线性颜色调整分开记录。用户显式指定配色或要求保留既有配色时优先遵从。

## 固定背景参考区

选择一块面积充足的无目标区域，或在较大区域内屏蔽天体后保留背景。排除无效覆盖、边缘伪影、坏点、恒星翼部、星系晕、透镜弧及可见弥散光；不能仅凭全图中位数、最低亮度像素或某个固定百分位宣称已选出天空。

结合全部通道的天体检测、掩膜扩张及较大尺度平滑检查低表面亮度结构。平滑仅用于选择/检查掩膜，不修改待校色像素。最终背景统计保留所选空间位置的原始线性样本，不逐通道另选暗像素。可使用多个干净区域组成同一固定掩膜，避免只有少数背景点。

检查并保存背景区域叠加图；报告有效面积、像素数、占有效视场比例和像素尺度。考虑重采样相关噪声，不能仅靠像素数量判定样本充分。将背景拆成若干空间子区检查中位数稳定性及梯度；如残余弥散光、梯度或区域不足使背景无法可靠估计，应重新选区或说明缺乏可靠参考，不能强行宣布中性化成功。无可见弥散光不代表已排除噪声以下的弥散成分。

背景区一旦确定，在增益调整、迭代预览和最终验证中保持不变。若有证据必须更换背景区，重新开始该轮估计并记录原因。此配色背景掩膜与自适应拉伸脚本的背景上限评估掩膜用途不同，需分别保存，不能混用统计结果。

## 线性变换与不变量

在共同有效的固定背景掩膜 M 上计算每通道中位数：

```text
b_c = median(I_c[M])
N_c = I_c - b_c + B
I'_c = a_c * (N_c - B) + B
     = a_c * (I_c - b_c) + B
```

B 是三个通道共享的背景值，默认 0；a_c 为正线性增益。先以 a_c=1 完成背景中性化，再围绕 B 调整增益。每次预览从同一线性输入及固定 b_c 重新计算，不累计乘上一次试验的增益。等价的加法常数是 `d_c = B - a_c*b_c`。当 B 非零时，不能直接将 N_c 乘 a_c，否则背景会再次偏色。

验证每一步和保存后 `median(I'_c[M]) ≈ B`，使用与数据动态范围、输出浮点精度相称的容差，记录残差；不允许用背景平均值替代中位数。检查最终 RGB 共享拉伸后同一区域的通道中位数及 PNG 量化差异；共享单调变换对偶数样本的数值中位数可能产生微小差异，应实测而非承诺逐位相等。量化、噪声或空间梯度也可能使视觉背景并非处处中性，需检查。

中位数对齐只约束固定掩膜上的统计中心，不保证每个像素、分布宽度、空间梯度或图像其他位置不变。每通道的增益也会缩放该通道的噪声。用同一背景掩膜和多个空间子区，比较线性配色前后及最终浮点图、PNG 的 RGB 中位数、分布宽度（如 16–84 百分位）、裁切与可见色斑；参考区不足或色偏、噪声明显时重选背景或减小增益，并说明局限。

## 椭圆星系参考配色

星系团场中若有多个可信的椭圆星系或早型星系，可将它们的颜色作为**定性显示参考**：参考对象的主体通常可呈近白至温暖黄橙色，但实际颜色受红移、滤镜、尘埃和恒星族影响，不能假定所有成员具有相同 RGB 或将其视为测光定标。

1. 尽量结合可靠星系目录、红移或其他资料确认成员与形态；没有证据时明确标记为目视候选，避免把恒星、前景星系和透镜弧当作已确认椭圆星系。选多个空间上独立的对象，保留对象间差异；数据不足时说明并使用其他参考或保守增益。
2. 在已配准的线性 RGB 上为每个候选选择覆盖主体的足够大区域，而非只取亮核；参考图和多波段共同检查形态、外晕及低表面亮度结构。排除邻近星系、恒星、衍射尖峰、透镜弧、无效覆盖和显著重叠；必要时使用候选掩膜而非强行判定混叠像素归属。阈值若用于剔除背景，应记录所用通道、值和排除弱外晕的偏差，不要逐通道各选一套像素。
3. 保持配色参考背景掩膜固定，用每个星系同一组空间像素分别测量线性 RGB 分布、中位数及稳健分位数，并画区域叠加图和每个星系的 RGB 直方图；保留各区域掩膜、有效像素数及 WCS。考虑相关噪声和背景/前景残留，避免把多个像素视为彼此独立的测量。
4. 结合各对象整体分布和可用的观测依据，从原始线性 RGB 及固定背景中位数出发，选取整幅图通用的正增益 `a_c`，使候选星系颜色整体合理、在近白与温暖色之间有自然差异；不要对每个星系单独调色，不固定通用 RGB 比例。增益尤其是蓝通道增益会放大噪声，需要检查背景分布和其它天体颜色。若候选混叠、颜色相互矛盾、弱波段信噪比不足或所需增益造成明显噪声，不强制调白，报告限制或改用其他参考。
   本用户对椭圆星系另有显示偏好：最终共享拉伸后，每个可靠参考区的 G 中位数都应略低于 R，不能等于或超过 R；也不要让两者过于接近而显得偏红。以完整固定椭圆区域计算各通道中位数，采用整幅图统一的正线性增益调整 G，并从同一线性配色输入重新运行共享拉伸。不能只在拉伸前令 G 位于 R、B 中点，因为非线性映射可能使最终显示中位数偏离该目标；应在共享拉伸后复核并迭代。不同参考对象有自然差异时，不要为强迫每个对象达到完全相同的差值而逐对象调色。
5. 保存校色线性文件及系数后，以 RGB **相同**的输入尺度、黑点、白点、MTF 与扩展参数从线性输入重新生成显示图。增益应在该共享映射下评估与迭代：为逐通道 MTF 调出的增益不能未经复核直接沿用。对比各星系配色前后线性分布和共享拉伸后的 RGB 分布、候选区域叠加图、背景子区与完整预览；允许个体自然差异，避免通过后期颜色工具强行统一。

## 目标颜色与增益选择

结合目标类型、滤镜映射、可信观测或文献检查显著偏色。常见目标颜色仅是合理性检查，不能作为所有对象都必须满足的硬模板；保留天体间真实相对差异，不强制所有弧为蓝色或所有星系为同一暖色。近红外映射到 RGB 必须称为代表色。没有标准星或光谱校准时，不宣称恢复真彩色或完成测光定标。

从中性化输入开始选择并记录增益；没有可靠理由调整时使用 1。对噪声较大的通道避免为追求颜色盲目放大。任何迭代都只改变整幅通道的正线性增益及相应背景补偿常数，随后从线性结果重新运行共享拉伸。某幅图的增益、区域尺寸和掩膜阈值不能固化为其他图的默认值。

## 记录与交付

保留线性输入路径及哈希、滤镜到 RGB 的映射、背景掩膜及区域图、面积/空间稳定性检查、b_c、B、a_c、d_c、选择依据和前后背景 RGB 统计。若用椭圆星系参考，另保留每个星系的候选身份及依据、掩膜/叠加图、逐星系 RGB 分布与统计、排除和限制。交付新的线性 FITS/TIFF、最终显示结果及参数记录。再次使用已校色线性文件时读取记录，避免重复中性化或累积增益。
