## 像素变换

输入给 HT 的像素 `x` 必须位于 `[0,1]`。五个参数为黑点 `s`、
白点 `h`、中间调 `m`、扩展下界 `l`、扩展上界 `r`。

1. 裁切并线性重标度：`u = clip((x-s)/(h-s), 0, 1)`。
2. 按文档公式 [1]：

   ```text
   MTF(u;m) = 0                              if u = 0
              1/2                            if u = m
              1                              if u = 1
              (m-1)*u / ((2*m-1)*u - m)      otherwise
   ```

   在本实现允许的 `0<m<1` 内，使用代数等价而数值更稳定的形式：
   `v = (1-m)*u / ((1-m)*u + m*(1-u))`，单独保证端点。
3. 依第 4 页动态范围扩展的文字定义重标度：
   `y = (v-l)/(r-l)`。

`m=0.5` 时 MTF 为恒等映射；`m<0.5` 提亮，`m>0.5` 压暗。
`MTF(m;m)=0.5`。恒等 HT 为 `(s,h,m,l,r)=(0,1,0.5,0,1)`。
扩展 `l=-1,r=2` 会把原 `[0,1]` 压入 `[1/3,2/3]`，不会恢复已裁切信息。
计算直接作用于浮点像素；直方图只用于诊断，不把图像预先量化到直方图桶。
这不是 gamma、对数、asinh 或直方图均衡化。

文档界面允许 `s=h` 及中间调端点，但这些是退化情况。脚本有意只支持
`0<=s<h<=1`、`0<m<1`、有限 `l<=0`、有限 `r>=1`，并拒绝非法值。
因此这是文档算法的常规非退化实现，不能标注为完整 PixInsight 替代实现。

## 输入尺度不是 HT 算法的一部分

有单位的天文 FITS 可含负数，且通常不在 `[0,1]`。
显式输入范围 `[a,b]` 对应 `x_raw=(data-a)/(b-a)`；
再把越界样本裁到 `[0,1]`，单独统计低端、高端裁切。
不要把这个输入映射与 HT 的 `s,h` 参数混淆。

- `auto`：无符号整数 TIFF 用类型量程（如 uint16 的 0–65535）；
  其他输入只有在全部有效样本已在 `[0,1]` 内时才接受。
- `minmax`：所有有效样本共同取最小/最大值；RGB 共享范围；不裁掉分位尾部。
  这是显示策略，受异常值影响，也可能受极端亮星支配。
- `--input-range a b`：可重复使用用户定义的同一显示尺度；
  越界样本比例写入 JSON。

常量图像无法用 minmax 定义有限宽度范围；应选择显式范围。
无效样本从归一化与参数估计中排除。VALID 掩膜的非零正值代表有效，
DQ 位标志需要另行解释，不能直接复用。

## 可选的目标中位数策略（仅显式请求时）

默认自适应工作流见 [adaptive.md](adaptive.md)：以亮结构的输入中位数设置 m，
并单独约束输出背景中位数；不使用本节的固定全图输出目标。

`--target-median t` 是保留的可选参数估计策略，不是原文的 AutoClip，
也不是 PixInsight STF 自动拉伸复刻。它以完成黑白点处理后的样本中位数
`q` 为锚点，并求使 `MTF(q;m)=t0` 的 `m`：

```text
t0 = l + t*(r-l)
m  = q*(1-t0) / (q + t0 - 2*q*t0)
```

要求 `0<q<1` 且 `0<t0<1`。目标 `t` 指动态范围扩展后的锚点输出；
偶数样本的统计中位数涉及插值，非线性变换后不保证与目标严格相等，
实际输出中位数会记录。共享参数时用所有通道样本的合并中位数，
逐通道参数不同时分别求值。不要默认把 `q` 叫做背景值。

## RGB、裁切与科学语义

共享曲线表示对每个 R/G/B 样本应用相同的非线性函数，不是亮度分量处理，
不能严格保持 `R:G:B` 比值。逐通道参数还可能明显改变色平衡。
真保色拉伸需要另一种明确约定的方法，不应在该实现中暗中加入。

JSON 中的裁切计数采用严格 `<s` / `>h`，表示范围外样本；等于边界的样本
单独在输出端点计数中反映。分母为各通道有效样本数，不使用 PixInsight
界面可达到 300% 的 RGB 合计显示约定。归一化越界和 HT 裁切分别统计，
不能简单相加成“损失像素总数”。预览的整数舍入可能额外产生黑白像素，
而浮点主产品无需这种量化。

每次输出记录源文件 SHA-256、所选 HDU/掩膜、通道轴、输入范围、
最终五参数、裁切及端点比例、软件版本、命令和输出校验结果。
原始数据保持原样，非线性输出不保留原来的物理单位语义。
